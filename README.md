# Projecao de Deficit — GDF 2026

Atualizacao diaria da projecao de deficit orcamentario (Comparativos 1, 2 e 3),
gerada a partir do banco e publicada como planilha + pagina.

- `etl.py` — gera a planilha `Analise_Deficit_2026_AAAA-MM-DD.xlsx`.
- Conexao com o banco fica em `config.py` (nao versionado; use `config_exemplo.py` como modelo).
